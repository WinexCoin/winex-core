# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.6.x   | :white_check_mark: |
| < 3.6   | :x:                |

## Reporting a Vulnerability

The WINEX Core development team takes the security of its decentralized network, consensus algorithms, cryptographic primitives, and client implementations very seriously.

If you believe you have discovered a vulnerability in the WINEX consensus protocol, RPC daemon, miner engine, or wallet key management:

1. **Do not open a public GitHub issue.** Publicly disclosing vulnerabilities before a patch is released puts all network participants at risk.
2. Please send detailed technical descriptions, reproduction scripts, or proof-of-concept code to:
   - **Email:** `support@winexcoin.com`
3. Include information on:
   - Affected component (`winex-node`, `winex-wallet`, `winex-miner`).
   - Software version and environment (OS, architecture, Go version).
   - Step-by-step instructions or test vectors to reproduce the behavior.
   - Potential impact on the consensus ledger or user funds.

We appreciate responsible disclosure and will work diligently to investigate and deploy patches promptly.
